# 药小伴产品评估（2026-09-05）

本评估结合用户三张真机截图、当前页面与业务逻辑。以下均为建议，本轮不实施产品改版；代码修改仅针对照片保存故障。

产品已有的基础应保留：药名与有效期即可完成录入；月份精度有计算说明；只管效期、固定服用与按需使用分开；余量标注为预计；记录可以撤销；照片失败保留药盒信息。

## 主要代码证据

- 提醒措辞与渠道状态：`miniprogram/pages/medicine-form/index.wxml`、`miniprogram/pages/medicine-detail/index.wxml`、`miniprogram/components/reminder-settings/index.wxml`。
- 按需使用入口：`miniprogram/pages/medicine-detail/index.ts` 中的 `recordExtra()` 与同目录 WXML。
- 照片呈现、模式主次：`miniprogram/pages/medicine-detail/index.wxml`。
- 状态标签与筛选：`miniprogram/pages/cabinet/index.ts`、同目录 WXML / WXSS。
- 真机布局：用户截图、`miniprogram/components/app-nav/index.wxss`、今天和药箱页面。
- 历史与导出：`miniprogram/pages/history/index.ts`、`miniprogram/pages/settings/index.wxml`。

## 建议验证方式

请 3—5 位目标用户分别完成：添加药盒后退出再进入核对照片；保存固定计划后说明提醒状态；记录并撤销一次按需使用；辨认同名药盒与已移除药盒；从只管效期详情中找到日期及其来源。记录能否独立完成、耗时和误解点，优先解决这些核心流程的问题。
